# Abdulkadir — Developer Portfolio

A responsive, single-page portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser. Google Fonts are loaded from the web; the site still works if fonts are unavailable.

## Publish free with GitHub Pages
1. Create a new public GitHub repository, e.g. `abdulkadir-portfolio`.
2. Upload `index.html` and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will provide the public website URL when deployment finishes.

You can also drag the folder into a static hosting service such as Netlify or Cloudflare Pages.

## Before sharing
- Check the project descriptions and links match the current state of each repository.
- Add live project URLs where available.
- Add a professional headshot if desired; the current hero uses a typographic illustration.
- Keep the contact email current.
